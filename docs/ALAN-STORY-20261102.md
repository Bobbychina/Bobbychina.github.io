# 墨狂 · 九关剧情与过场

游戏入口为 `/games/alan/`，演出预览为 `/games/alan/story-preview.html`。墨狂原作者为 Alan；本次只迭代剧情及演出，保留网站既有作者标注。

## 内容与维护入口

九关各有入境与余波，共 18 段、56 镜。主线保留半枚雷纹玉佩、红绳、同行者、噬色无相与归墨台，增加同行者主动引墨离村、撤离标记、倒影辨向及两人配合脱身的因果关系。画面使用程序水墨背景、剪影动作、物件特写与镜头变化，没有新增配音或配乐。

- `games/alan/src/story-content.js`：文案、分镜顺序、景别、焦点、动作与时长。
- `story-timeline.js`：分镜采样、时长与下一镜边界。
- `story-renderer.js` 与 `story.css`：演出画面及横竖屏布局。
- `story-director.js`：关卡状态与演出控件接入。
- `story-preview.js`：独立预览页；不读取或改写存档。
- `legacy-runtime.js`：从当前受防护的游戏页面提取的运行时，保留原游戏逻辑。

游戏内 Enter/下一镜推进一镜，最后一镜进入战斗或结算；空格/跳过整段沿用原跳过流程；P/Esc 暂停。正常播放结束后自动继续。每镜 5–7.5 秒，战斗时间不包含演出时间。

## 完整性与存档边界

基于 `c541878` 的 InkGuard 2.0.0 接入，没有以旧页面覆盖防护更新。原运行时只新增两个入口：定义游戏类之后、冻结其原型之前安装剧情时长；原绘制完成之后绘制演出。

“下一镜”的改动经过游戏闭包内的回调：先执行 Guard.check，确认没有帧外修改，再推进剧情时间，最后用闭包原有许可执行 accept。许可对象不会传给剧情模块或暴露为全局变量。剧情 API 和全局属性不可替换，保留原引擎原型与渲染 API 冻结。最终跳过仍点击原按钮，由原结算逻辑完成；没有改动货币、角色成长、解锁条件或存档格式。
