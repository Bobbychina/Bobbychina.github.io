# 纯走路 · 梦核（dreamcoreWalk）

给 CarlinNearl 的「纯走路梦核」：**没有敌人、没有追逐、没有目标**，只有走廊、灯、水声，和你自己的脚步。

## 玩

双击 `index.html` 即可（单文件、零依赖、离线可玩、可直接发给别人）。

| 按键 | 作用 |
|---|---|
| W A S D / 方向键 | 走路 |
| 鼠标 / ← → | 转视角（点画面锁鼠标，Esc 松手） |
| Shift | 慢走 |
| P | 拍照模式（去 HUD，加胶片边框） |
| O | 存下这一帧 PNG |
| M | 静音 |

## 里面有什么

- 射线渲染（raycaster）写像素的 PSX 风格第一人称步行，纯 canvas 2D，无任何外部库
- 26 个房间、8 种梦核分区：黄墙走廊 / 池核 / 办公室 / 老房子 / 地下车库 / 白瓷间 / 空教室 / 旧病房；走错门会在同分区里"循环"回来（梦的常见毛病）
- 心理恐怖但不吓人：灯管闪烁、随机熄灯、远处的电话铃、身后的门轻轻合上、隔壁的敲击声、走廊尽头站着一个人——**你走近他就消失，他不追你**
- 惬意的那部分：低频 drone、雨声、灯管嗡鸣、脚步、偶尔一声钟；镜头有走路起伏和呼吸感
- 全部贴图/道具/音频都是运行时程序化生成的（壁纸、瓷砖、地毯、混凝土、木墙、木箱、台灯、植物、电视雪花、海报、钟、人体剪影）
- 自适应分辨率：帧率掉了自动降内部分辨率，卡不卡都尽量保持 60fps

## 技术备忘

- 调试接口：`window.__dream`（`tick(n,keys)` 手动推帧、`gotoZone(i)`、`lumFull()` 亮度分带、`blackRect()` 假黑块检测、`faceProp(d)` 面向最近道具）
- 渲染顺序：地面/天花板整屏投射 → 墙 DDA → 公告牌精灵（z-buffer 遮挡）→ 上屏后处理（分区色调 / 颗粒 / 扫描线 / 暗角 / 轻 VHS 撕裂）
- 踩过的坑：贴图打包时高字节必须保留真实 alpha（写死 0xFF 会把所有道具变成黑方块）；亮度打包进像素前必须夹到 255，否则通道溢出成花屏；`forEach` 里不能 `continue`
