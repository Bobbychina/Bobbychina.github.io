# 吸血鬼幸存者：本地开发说明

游戏入口为 `index.html`，页面按顺序加载 `js/` 下的经典脚本。开发时从站点仓库根目录启动本地 HTTP 服务器，例如 `python -m http.server 8000`，然后访问 `/games/vampire-survivors/`。

## 霜钟回廊与余烬熔庭

战役共四关。第一、二关各 15 分钟，第三、四关各 12 分钟，总时长 54 分钟。四关全程继承玩家等级、武器、流派、被动、宠物、遗物与金币；第二关 config 明确 `fresh:false`。新关卡在本关 10 分钟出现必须击杀的章节首领，12 分钟结算时未击败则判负。

| 新章节 | 首领与时间 | 场景机制 |
| --- | --- | --- |
| 第三关 · 霜钟回廊 | 04:00 霜钟守望；10:00 霜冕女王 | 90 秒后开始周期寒潮；寒意过高会减速，满值持续受伤；靠近暖灯回温。闪避速度不受寒意影响。 |
| 第四关 · 余烬熔庭 | 10:00 熔心巨像 | 横纵地火交替喷发，有预警；站在青色卸压阀旁 1.2 秒能清除地火并取消下轮喷发。还能打断巨像攻击，产生 2 秒的 ×1.35 受伤窗口。 |

三位新首领各有三种攻击并在半血后加快施放。霜钟守望使用带缺口的钟环、扇形冰针和延迟冰裂；霜冕女王使用交叉射线、交替钟环与冰牢落点；熔心巨像使用旋转扫射、喷发区域和交错弹幕。击杀后回收对应攻击，避免结算期间残留伤害。

新增八种常规敌人：铸霜卫士（举盾减伤，闪避贴近破盾）、冰棱猎手（保持距离瞄准）、霜咬猎犬（预警冲锋）、鸣钟幽灵（治疗普通敌人）、爆燃虫（接近后蓄力自爆）、余烬术士（预判延迟轰击）、黑曜重骑（两段冲锋）、熔核黏团（死亡裂变）。裂变幼体不再裂变，也不进入常规抽取池。

完整战役从第一关开始。内部测试用 `Game.start(g)` 开一局后，再用 `Game.startLevel(g,index)` 设置目标关卡；`startLevel` 是内部推进函数，不是玩家跳关入口。

新章节在 01:30 与 05:30 生成遗物祭坛，靠近后额外三选一，不消耗金币，也没有升级待选队列。每件遗物本局唯一，随构筑继承，新开一局清空：

| 遗物 | 实际效果 |
| --- | --- |
| 玉霜符 | 范围 ×1.18，移动速度 ×0.95 |
| 熔心残片 | 伤害 ×1.20，最大生命 ×0.88，当前生命限制到新上限 |
| 旅者铭牌 | 移动速度 ×1.12，拾取范围 ×1.18 |
| 余时沙漏 | 攻速 ×1.15，闪避冷却 ×0.90 |
| 护灯之誓 | 每秒回血 +1，生命上限与当前生命 +15 |
| 碎镜印 | 暴击率 +8 个百分点，额外弹数 +1，护甲 -1 |

定义位于 `chapters-config.js`；行为、攻击与容量限制在 `encounters.js`；地图周期、遗物与额外选择在 `stages.js`；像素精灵、装饰和预警在 `chapter-art.js`。精灵与受击剪影只缓存两帧，地面和装饰一次烘焙，战斗帧不新建渐变。新环境的慢速倍率单独存放，不反复修改永久移速。

## 金币商店与经济

游戏不再有升级选卡、重选次数或待选卡队列。所有强化从商店购买，商店初始 30 金币；每次升级（包括经验升级、超级经验球和首领奖励升级）只发 12 金币/级，保持 `playing`，不送免费强化、不弹面板。普通经验球按 `ceil(xp)` 掉钱，金色经验球按 `ceil(xp / 100) * 3`，超级经验球固定 40 金币；首领额外给 `100 + chapterIndex * 50` 赏金。拾取入口在 `pickups.js`。

按 B 或点击 HUD 金币按钮可打开商店，战斗暂停；暂停菜单中打开则关闭后回到暂停。货架固定 4 格，每 60 秒战斗时间免费补货，锁定商品保留；免费补货与过关会重置本轮付费刷新次数。付费刷新费用为 `5 + 2 × 本轮已付费刷新次数`，最高 100；锁定的商品保留生成时的 token 与价格。售价随本局购买次数上涨，基础价按商品种类计算后乘以 `1 + 0.035 × 购买次数` 并向上取整。钱不够、token 过期、商品已售或已失效时返回失败，不扣钱；购买后原槽位标记为已售。关闭再打开不会补货。

经验球生成时记录独立的金币价值，达到实体上限后合并经验与金币，避免普通球、金球混合后按外观重新折算。普通经验不合并到只升等级的超级球。宠物随整局保留，现有三只宠物均可在首个首领后的选择中取得。

全场满构筑且满血时，战役允许没有可购买商品；无尽模式仍会供应尚未到属性上限的 `power` / `guard`，受伤时供应 `heal`。遗物三选一仍免费，不占金币，`relicselect` 状态保留。

| 模块 | 职责 |
| --- | --- |
| `js/game/shop.js` | 金币、价格、4 格货架、刷新/锁定/购买校验与经济边界 |
| `js/game/game.js` | 状态机、`upgradePool` / `_applyChoice`、四关推进与继承、练习升级 |
| `js/game/pickups.js` | 经验球实际拾取并调用金币奖励 |
| `js/ui/panels.js`、`css/shop.css` | 商店界面、构筑说明与结果反馈 |
| `js/core/input.js`、`js/main.js` | B 打开/关闭、R 刷新、1–4 购买与 HUD 接线 |
| `js/core/cheats.js` | 99 级练习码，只发等级与金币 |

以上是逻辑层的规则与接口。金币拾取和商店购买的战斗内实际集成、浏览器布局与触屏操作仍需要在页面中验证。

## 武器与流派

共 16 把基础武器，每局最多携带 4 把。原有八把为魔法飞弹、腐化光环、环绕骨刃、血爆新星、柠檬喷射器、雷击链、寒霜飞锥、陨星术；新增八把及其 24 条互斥分支如下。每把新武器本局只能选一条分支，每条最高 3 级。武器升级不占用分支等级。

| 新武器 | 战斗机制 | 三条分支 |
| --- | --- | --- |
| 回魂镰 | 飞出并返回，两个方向各命中一次 | 收割：回程真实命中治疗；双月：额外镰刃；引魂：普通敌人牵引 |
| 圣枪 | 直线贯穿突刺 | 处刑：低血目标增伤；回声：延迟追加突刺；壁垒：无敌帧与击退 |
| 符文地雷 | 布防后接近触发范围爆炸 | 连锁爆破：引爆邻近已布防地雷；霜纹：减速；破片：径向弹丸 |
| 风暴图腾 | 地面固定、多目标周期雷击 | 分岔：更多目标；静电：同目标第三跳增伤；风眼：持续牵引 |
| 机械蜂群 | 环绕无人机自动开火 | 锁敌：优先精英/首领并增伤；修复：每群每五秒治疗一次；交叉火力：双发与穿透 |
| 引力球 | 移动引力场、周期伤害 | 坍缩：消失时爆炸；深井：留地继续生效；潮汐：交替吸入与推出 |
| 焰舌 | 扇形直接伤害与燃烧 | 野火：死亡传播最多一代；熔炉：缩窄扇面提高伤害；余烬：地面持续伤害 |
| 棱镜 | 可扫动的持续贯穿光束 | 折射：三束；过载：固定方向增伤；映照：背后光束并延长持续时间 |

初始武器有 11 个选择：魔法飞弹、寒霜飞锥、陨星术和八把扩展武器。图鉴列出全部武器、流派说明和进化配方。第二关专属武器仍遵守关卡解锁条件；无尽模式在 10 分钟后解锁。

`js/game/arsenal-config.js` 定义新武器和纯数值分支，`js/game/arsenal.js` 负责实体、判定与分层渲染。`Weapons.chooseSchool` 验证持有关系、互斥与等级上限，`statsFor` 每次从基础值计算，不反复累加分支数值。所有实体受 `C.ARSENAL_LIMITS` 限制。首领免疫减速和牵引；收割治疗不从首领免疫命中产生。

## 战役与无尽

战役采用上述四关流程。无尽模式没有时间终点，不因 15 分钟到达而过关；整局保留等级、武器、分支、宠物、遗物与金币。每 180 秒提升一波，每 300 秒安排下一只首领（场上最多一只，未击杀时推迟）。10 分钟进入深渊，20 分钟进入霜钟回廊，30 分钟进入余烬熔庭；之后每 10 分钟交替新场景。场景轮换时商店重新供货，已购买次数与金币保留。新场景优先安排对应新首领，随后加入既有轮换，不重置构筑。

敌人的生命、伤害和速度按 `C.ENDLESS` 增长并设倍率上限，敌人和弹幕数量仍有硬上限。无尽玩家可超过 99 级，后续升级经验采用受控增长；满构筑继续提供治疗、伤害和护甲补给。暂停菜单可主动结束并结算；结算后可重试或返回菜单更换模式和武器。

沿用 `vampire_survivors_save_v1` 本机存档，原战役字段保留，新增 `endless` 子对象保存无尽最高时间、击杀、局数和前五。两种模式的个人榜分开，无尽不提交战役全站榜。

## 站点账号与本机纪录

开始面板使用 `/games/site-auth.js` 的站点 OAuth + PKCE 登录，支持弹窗与失败后的整页登录。只请求 `openid profile arcade`，不请求存档或邮箱权限。退出只撤销本游戏授权，不退出整个站点。昵称使用文本节点显示。

现有全站榜仍使用游戏厅会话，因此 `/games/account.js` 仅负责既有排行榜身份桥接。用户点击连接时，先验证站点 Cookie 与游戏授权的身份相同，再连接排行榜；换号和会话过期时重新连接。提交前必须同时满足本游戏授权、身份一致和有效排行榜会话。读取排行榜无需登录。

游戏不加载 `site-saves.js`、`core/cloud.js`、`ui/cloud-ui.js`，不调用存档上传/下载或 Gist API。取消游戏云存档功能不删除其他游戏存档或远端历史数据。皮肤、静音与两种模式纪录只保存在当前浏览器。

## 寒霜、陨星与进化

重试会重新开一局；进入第二至第四关则沿用所选初始武器和全部已购构筑（第二关 `fresh:false`）。未持有的初始武器也会进入商店货架。寒霜飞锥发射直线扇形冰弹并限时减速普通敌人，首领免疫控制。陨星术会锁定敌人所在位置，预警结束后按实际落点结算范围伤害，敌人移出落点即可避开。

武器满级并满足以下被动配方后，下一次补货在有未锁定槽位时优先上架可用进化；进化沿用武器栏位并保留流派，不自动替换其他武器。

| 进化 | 配方 | 独立效果 |
| --- | --- | --- |
| 追星弹幕 | 魔法飞弹 Lv.8 + 多重射击 Lv.2 | 命中后转向其他未命中的敌人 |
| 噬魂领域 | 腐化光环 Lv.8 + 再生 Lv.2 | 实际命中回复生命，每脉冲最多 2 点，并减速普通敌人 |
| 极夜冰棺 | 寒霜飞锥 Lv.8 + 范围扩张 Lv.2 | 冰锥命中碎裂，造成范围伤害与 75% 减速 |
| 天坠星群 | 陨星术 Lv.8 + 力量增幅 Lv.3 | 每轮多落一颗陨星，每颗落地后再造成一次 50% 伤害的震爆 |

`C.EVOLUTIONS` 保存配方与数值变化，`VS.Weapons.evolutionStatus/evolve/statsFor` 统一查询和应用。减速由 `VS.Enemies.slow` 处理，保留基础速度，计时结束后恢复。陨星和碎裂表现分别受 `C.WEAPON_EFFECTS.MAX_METEORS/MAX_BLASTS` 限制；伤害计算使用独立查询数组，避免覆盖弹道正在遍历的命中列表。

运行 `node tools/vs-content-check.cjs` 检查初始武器与第二关继承、减速、陨星预警与落地、四条进化配方、商店进化购买及实体上限。渲染和触屏仍需在浏览器中验证。

## 属性与强化数值

- 商店商品上的数值是武器基础值，不含被动、流派与关卡倍率；购买后立即生效，失败不会扣钱。
- 迅影步伐每层将闪避冷却乘以 0.85；背水之力在生命不高于一半时，每层使武器伤害增加 18%；战地包扎每层立即回复最大生命的 25%，并增加每秒 0.3 的生命回复。投射物的伤害在发射时计算。
- 触屏设备可用右下角按钮闪避；获得环绕骨刃后也可切换范围。

数值和技能定义在 `js/game/config.js`；商店规则在 `js/game/shop.js`；状态机、合法池与关卡推进在 `js/game/game.js`；商店界面在 `js/ui/panels.js`。运行 `node tools/vs-levelup-check.cjs` 可检查真实购买、金币不足不扣钱、重复购买、升级只发金币、四关继承、满构筑无货可买和三项被动的实际数值。浏览器布局与触屏交互仍需实际打开页面验证。

## 控制台练习码

先开始一局，然后在浏览器 Console 输入 `bobbychina32747("314159265358979367679178")`。当前角色直接升到 99 级，每级实际发放 12 金币，但不再补选卡、不打开商店，也不改变当前游戏状态；正在选择宠物或遗物时面板保留。重复调用不额外加金币，无尽模式已经超过 99 级时不会降级。新开一局会清除练习标记。

这类练习局保存本机成绩，但不会自动提交全站排行榜，结算页会标明。原写法 `bobbychina32747.314159265358979367679178` 不是合法 JavaScript；点号后不能直接跟数字，长数字也不能用 Number 精确表示，因此入口使用函数和字符串暗号。

## 验证

从游戏目录运行 `node tools/vs-shop-check.cjs`、`node tools/vs-levelup-check.cjs`、`node tools/vs-content-check.cjs`、`node tools/vs-expansion-check.cjs` 和 `node tools/vs-chapters-check.cjs`。站点仓库根目录还需运行 `node tools/i18n-check.mjs`。

- `vs-shop-check.cjs`：18 组金币与购买边界，含真实拾取、满场合并、过期商品、互斥流派、锁定保价、补货时钟、跨关金币与练习码。
- `vs-levelup-check.cjs`：商店真实购买与价格扣费、金币不足与重复购买不扣钱、升级/首领奖励只发金币、四关继承、满构筑无货、迅影步伐/战地包扎/背水之力的实际计算。
- `vs-content-check.cjs`：初始武器与第二关继承、寒霜扇形与限时减速、陨星预警/落点/震爆、四条进化配方与商店购买、实体上限。
- `vs-expansion-check.cjs`：26 组扩展武器、互斥分支、实体上限、无尽首领轮换与换货、超过 99 级、满构筑补给、两种模式独立存档和控制台练习码。
- `vs-chapters-check.cjs`：18 组新章节行为，覆盖通关门槛、第二/三/四关金币与构筑继承、寒潮与暖灯、地火与卸压、护盾与冲锋、远程预警、治疗与裂变、三位首领、钟环缺口、遗物免费选择与 99 级练习码衔接、无尽轮换及实体硬上限。

`tools/vs-boss-probe.mjs` 在招式检查阶段暂停玩家输出，避免随机构筑提前击杀首领。输出检查使用固定 60Hz 逻辑步长与受保护测试角色测量 TTK，实时渲染帧率另行测量；该 TTK 不代表真人生存率。

`tools/vs-probe.mjs` 使用自有测试浏览器的 CDP 端口检查页面、开局、站点账号入口、云存档移除与本机纪录。真实账号授权不应使用桩结果替代验收；隔离浏览器可检查弹窗路由和授权范围，身份切换、失败和退出行为使用桩测试，不读取真人凭证。

逻辑脚本不能替代浏览器验收。发布时还需验证 B 键和 HUD 商店入口、金币变化、实际购买、刷新与锁定、桌面和触屏布局、缺失模块提示，以及发布后公网资源。模拟触屏结果不能代表真实手机性能；固定时钟和受保护角色不能替代完整战役的人工平衡验收。
