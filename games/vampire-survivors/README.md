# 吸血鬼幸存者：本地开发说明

游戏入口为 `index.html`，页面按顺序加载 `js/` 下的经典脚本。开发时从站点仓库根目录启动本地 HTTP 服务器，例如 `python -m http.server 8000`，然后访问 `/games/vampire-survivors/`。

## 武器与流派

共 16 把基础武器，每局最多携带 4 把。原有八把为魔法飞弹、腐化光环、环绕骨刃、血爆新星、柠檬喷射器、雷击链、寒霜飞锥、陨星术；新增八把及其 24 条互斥分支如下。每把新武器本局只能选一条分支，每条最高 3 级。武器升级不占用分支等级。

| 新武器 | 战斗机制 | 三条分支 |
| --- | --- | --- |
| 回魂镰 | 飞出并返回，两个方向各命中一次 | 收割：回程真实命中治疗；双月：额外镰刃；引魂：普通敌人牵引 |
| 圣枪 | 直线贯穿突刺 | 处刑：低血目标增伤；回声：延迟追加突刺；壁垒：无敌帧与击退 |
| 符文地雷 | 布防后接近触发范围爆炸 | 连锁爆破：引爆邻近已布防地雷；霜纹：减速；破片：径向弹丸 |
| 风暴图腾 | 地面固定、多目标周期雷击 | 分岔：更多目标；静电：同目标第三跳增伤；风眼：持续牵引 |
| 机械蜂群 | 环绕无人机自动开火 | 锁敌：优先精英/首领并增伤；修复：每群每五秒治疗一次；交叉火力：双发与穿透 |
| 引力球 | 移动引力场、周期伤害 | 坍缩：消失时爆炸；深井：留地继续生效；潮汐：交替吸入与推出 |
| 焰舌 | 扇形直接伤害与燃烧 | 野火：死亡传播最多一代；熔炉：缩窄扇面提高伤害；余烬：地面持续伤害 |
| 棱镜 | 可扫动的持续贯穿光束 | 折射：三束；过载：固定方向增伤；映照：背后光束并延长持续时间 |

初始武器有 11 个选择：魔法飞弹、寒霜飞锥、陨星术和八把扩展武器。图鉴列出全部武器、流派说明和进化配方。第二关专属武器仍遵守关卡解锁条件；无尽模式在 10 分钟后解锁。

`js/game/arsenal-config.js` 定义新武器和纯数值分支，`js/game/arsenal.js` 负责实体、判定与分层渲染。`Weapons.chooseSchool` 验证持有关系、互斥与等级上限，`statsFor` 每次从基础值计算，不反复累加分支数值。所有实体受 `C.ARSENAL_LIMITS` 限制。首领免疫减速和牵引；收割治疗不从首领免疫命中产生。

## 战役与无尽

战役保持双关流程。无尽模式没有时间终点，不因 15 分钟到达而过关；整局保留等级、武器、分支与宠物。每 180 秒提升一波并将重选次数补到 2，每 300 秒安排下一只首领（场上最多一只，未击杀时推迟），尸潮之王与柠檬猪轮换。10 分钟后进入深层环境并加入第二关专属内容，不重置构筑。

敌人的生命、伤害和速度按 `C.ENDLESS` 增长并设倍率上限，敌人和弹幕数量仍有硬上限。无尽玩家可超过 99 级，后续升级经验采用受控增长；满构筑继续提供治疗、伤害和护甲补给。暂停菜单可主动结束并结算；结算后可重试或返回菜单更换模式和武器。

沿用 `vampire_survivors_save_v1` 本机存档，原战役字段保留，新增 `endless` 子对象保存无尽最高时间、击杀、局数和前五。两种模式的个人榜分开，无尽不提交战役全站榜。

## 站点账号与本机纪录

开始面板使用 `/games/site-auth.js` 的站点 OAuth + PKCE 登录，支持弹窗与失败后的整页登录。只请求 `openid profile arcade`，不请求存档或邮箱权限。退出只撤销本游戏授权，不退出整个站点。昵称使用文本节点显示。

现有全站榜仍使用游戏厅会话，因此 `/games/account.js` 仅负责既有排行榜身份桥接。用户点击连接时，先验证站点 Cookie 与游戏授权的身份相同，再连接排行榜；换号和会话过期时重新连接。提交前必须同时满足本游戏授权、身份一致和有效排行榜会话。读取排行榜无需登录。

游戏不加载 `site-saves.js`、`core/cloud.js`、`ui/cloud-ui.js`，不调用存档上传/下载或 Gist API。取消游戏云存档功能不删除其他游戏存档或远端历史数据。皮肤、静音与两种模式纪录只保存在当前浏览器。

## 寒霜、陨星与进化

重试和进入第二关时沿用所选初始武器，其余构筑遵循关卡重置规则。未持有的初始武器也能从升级卡取得。寒霜飞锥发射直线扇形冰弹并限时减速普通敌人，首领免疫控制。陨星术会锁定敌人所在位置，预警结束后按实际落点结算范围伤害，敌人移出落点即可避开。

武器满级并满足以下被动配方后，升级选卡保证出现至少一条可用进化；进化沿用武器栏位并保留流派，不自动替换其他武器。

| 进化 | 配方 | 独立效果 |
| --- | --- | --- |
| 追星弹幕 | 魔法飞弹 Lv.8 + 多重射击 Lv.2 | 命中后转向其他未命中的敌人 |
| 噬魂领域 | 腐化光环 Lv.8 + 再生 Lv.2 | 实际命中回复生命，每脉冲最多 2 点，并减速普通敌人 |
| 极夜冰棺 | 寒霜飞锥 Lv.8 + 范围扩张 Lv.2 | 冰锥命中碎裂，造成范围伤害与 75% 减速 |
| 天坠星群 | 陨星术 Lv.8 + 力量增幅 Lv.3 | 每轮多落一颗陨星，每颗落地后再造成一次 50% 伤害的震爆 |

`C.EVOLUTIONS` 保存配方与数值变化，`VS.Weapons.evolutionStatus/evolve/statsFor` 统一查询和应用。减速由 `VS.Enemies.slow` 处理，保留基础速度，计时结束后恢复。陨星和碎裂表现分别受 `C.WEAPON_EFFECTS.MAX_METEORS/MAX_BLASTS` 限制；伤害计算使用独立查询数组，避免覆盖弹道正在遍历的命中列表。

运行 `node tools/vs-content-check.cjs` 检查初始武器、减速、陨星预警与落地、进化配方及独立效果。渲染和触屏仍需在浏览器中验证。

## 升级选择

- 每关有 2 次重选机会。重选不消耗升级次数，优先抽取当前未展示的技能；可选池不足时允许原选项再次出现。进入下一关时次数重置，不写入存档。
- 武器卡上的前后数值是武器基础值，不含被动、流派与关卡倍率；当前构筑区列出武器、关键属性和已有被动。
- 迅影步伐每层将闪避冷却乘以 0.85；背水之力在生命不高于一半时，每层使武器伤害增加 18%；战地包扎每层立即回复最大生命的 25%，并增加每秒 0.3 的生命回复。投射物的伤害在发射时计算。
- 触屏设备可用右下角按钮闪避；获得环绕骨刃后也可切换范围。

数值和技能定义在 `js/game/config.js`；抽卡与关卡重置在 `js/game/game.js`；界面在 `js/ui/panels.js` 和 `css/levelup.css`。运行 `node tools/vs-levelup-check.cjs` 可检查重选、连续升级、技能效果、关卡重置和空卡池恢复。浏览器布局与触屏交互仍需实际打开页面验证。

## 验证

从游戏目录运行 `node tools/vs-content-check.cjs`、`node tools/vs-levelup-check.cjs` 和 `node tools/vs-expansion-check.cjs`。第三项覆盖 24 组扩展武器、互斥分支、实体上限、无尽首领轮换、超过 99 级、满构筑补给和两种模式独立存档。站点仓库根目录还需运行 `node tools/i18n-check.mjs`。

`tools/vs-probe.mjs` 使用自有测试浏览器的 CDP 端口检查页面、开局、站点账号入口、云存档移除与本机纪录。真实账号授权不应使用桩结果替代验收；隔离浏览器可检查弹窗路由和授权范围，身份切换、失败和退出行为使用桩测试，不读取真人凭证。
